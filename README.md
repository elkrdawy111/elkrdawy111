## 📊 Projects

### 1. AURA — E-Commerce Data Analytics Graduation Project
🔗 [GitHub Repository](https://github.com/elkrdawy111/ecommerce-data-analytics-graduation-project)

An end-to-end analytics project built around a fictional fashion e-commerce business selling clothing, shoes, bags, and accessories. It was a graduation/educational project.

- **Data:** Custom-generated data covering 2024–2026. The dataset was created specifically for this project and was not taken from Kaggle or any ready-made public dataset.
- **Database:** `E_COMMERCE_DB` in SQL Server, a normalized relational design with 14 tables, including Customer, Category, Brand, Supplier, Product, Promotion_Type, Promotion, Order_Status, Orders, Order_Items, Payment, Shipping, and Review.
- **Approximate data size:** 60 customers, 180 orders, 451 order items.
- **Work included:**
  - Database creation, synthetic data generation, and data insertion
  - Data cleaning and validation
  - Exploratory Data Analysis with Matplotlib and Seaborn
  - SQL analysis using computed columns, SQL Views, and T-SQL
  - KPI analysis and data visualization
  - A 5-page Power BI dashboard
- **Tech stack:** SQL Server, T-SQL, Python, Pandas, Faker, Excel, Power BI, Matplotlib, Seaborn
